# Demo EV Charger Hero Image

This folder contains a **high‑resolution hero illustration** of an electric vehicle charging station designed for premium website marketing.

- **File name:** `ev_charger_demo.png` (generated PNG; you can convert to WebP/AVIF for production).
- **Resolution:** 1920 × 1080 px (suitable for desktop hero banners).
- **Aspect Ratio:** 16:9.
- **Visual style:**
  - Soft ambient lighting, minimalistic garage background.
  - Glass‑like reflections on the charger surface.
  - Vibrant colour palette that matches the Envizon brand.
- **Intended use:**
  - Homepage hero section.
  - Marketing collateral or landing‑page ads.
  - Can be resized with `srcset` for responsive layouts.

## Recommendations
1. **Convert** the PNG to **WebP** (quality 80) and **AVIF** for modern browsers.
2. Generate responsive variants (2400 px, 1200 px, 600 px widths) using a tool like `sharp`.
3. Add appropriate `alt` text, e.g.,
   ```html
   alt="Modern EV charger installed in a residential garage with a plugged‑in electric car"
   ```
4. Use a `<picture>` element with `srcset` to serve the optimal format.

Feel free to replace this demo image with your own photography or 3‑D renders while keeping the same naming convention.
